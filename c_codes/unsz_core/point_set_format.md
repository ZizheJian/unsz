# UNSZ点集格式

当前实验版本支持最多两个点集。`get_point_set_id()`负责划分规则；Katrina中点集0是普通值，点集1是`-99999`，Ocean temperature只有点集0。

空间预测结构只根据坐标建立一次并在所有数据文件间共享。标签预测正确时保存0，错误时保存1；因为只有两个点集，解压时遇到1即可翻转预测标签。数值预测只使用已经重建且属于同一点集的参考点；常量点集只保存常量和值数量，不保存量化索引。

数值codec目前包括反比例预测、局部仿射拟合、常量以及实验性的`hybrid_loo`。`hybrid_loo`用同一组重构参考值比较IDW和局部拟合的leave-one-out绝对误差，压缩和解压独立得到相同选择，因此不保存逐点selector bit。

`.unsz`包含以下内容：

1. magic、版本、点数、数据类型字节数和点集数量；
2. 点集标签的位置差分经过Zstd后的流长度和字节；
3. 每个点集的编码方式、点数、最小值、最大值、量化索引数量，以及该点集量化索引先做Huffman、再单独做Zstd后的流长度和字节。

实验参数`-multi-huffman-experimental`支持`none`、`round`、`block`和`block_round`。非`none`模式下，每个点集按预测轮、独立空间块或二者组合划分量化索引，分别建立带树头的Huffman流；分组数量、各组量化索引数量、各Huffman流长度和全部Huffman字节拼接后只做一次Zstd。该模式不写入通用文件头，解压时必须指定与压缩时相同的参数。

标签流和各数值流分别进行Zstd压缩，不再对整个文件联合Zstd，因此可以直接统计每条流的大小。

二分类标签预测结果按原始点编号排列，只保存错误位置的差分并使用变长无符号整数编码，然后单独进行Zstd压缩。当前默认Zstd level为3，以便与UMC保持一致；候选编码和不同level的长度可以通过`s1_compress -data-dir <目录> -variable <变量名> -time-step '[0,0]' -M REL <误差> -label-stats`重新统计。

点集标签预测器支持三类状态更新：`inverse_proportion`在每个点后立即使用真实硬标签；`continuous_actual`在预测正确时保留连续预测值，预测错误时改为真实0/1；`continuous_reflect`在预测正确时保留连续预测值，预测错误时改为`1-predicted_value`。压缩和解压时由用户选择相同方案。

文件不保存相对或绝对误差上限。解压时用户必须通过`-M REL <eb>`或`-M ABS <eb>`提供与压缩时相同的模式和EB。REL模式会根据每个点集自己的最大值和最小值计算绝对EB，ABS模式则让所有非常量点集使用同一个绝对EB。

预测结构仍由外部坐标文件重建。预测轮数、候选/实际参考点数量、标签参考点数量、距离指数、是否变换坐标、误差模式和EB等参数都不保存在文件中，压缩和解压时必须由实验脚本保证参数一致。当前坐标变换矩阵仍在源码中，因此使用坐标变换的文件还要求压缩端和解压端采用同一个矩阵。

命令行统一使用显式命名参数，参数顺序不限。例如：`s1_compress -data-dir <目录> -variable attr0 -time-step '[0,10]' -M REL 0.01 -max-ref-num 10 -actual-ref-num 10`。`-time-step`接受带开闭端点的区间或显式列表，例如`'(0,10]'`、`'[0,10)'`和`'{0,3,7}'`。Shell可能展开方括号或花括号，因此时间表达式应放在单引号或双引号内。解压时使用相同参数。

当前反距离权重使用欧氏距离的`-3.61`次方。底层距离函数返回平方距离，所以实现写作`pow(squared_distance,-3.61/2)`，与`t7_coefficients.py`中基于`cKDTree.query()`返回的欧氏距离所训练的指数一致。
