# RBF最小参考点数公平测速

在通用“剩余参考点不可能达到门槛时提前回退”优化下，比较`min=7/8/10,max=10`的核心压缩、解压及总时间。仅测试受最小同类参考点门槛影响的双点集E3SM、Haiyan和Katrina。

每个数据在同一任务和节点内运行四轮完整五点曲线，顺序分别为`10→7→8`、`8→7→10`、`7→10→8`和`8→10→7`。后两轮将10/10固定在中间，用于排除第一轮和第二轮观察到的执行顺序偏差。汇总时先计算候选相对于同轮10/10的时间比，再对各轮和三个数据取几何平均。

最终版本完整保留`min==max`原有的首次缺失即回退路径，只为`min!=max`增加通用提前回退。第一次将通用判断同时放入10/10热循环的结果保留在父目录但不参与最终汇总；正式重跑结果位于`preserve_min_equal_fast_path`。
