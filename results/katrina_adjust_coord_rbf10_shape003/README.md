# Katrina当前RBF配置的坐标变换重训

训练使用当前空间配置：RBF10、Matérn-3/2、shape `0.03`、nugget `1e-6`、无趋势项、10000个第二阶段训练目标，以及`prediction_ggd_bit`离散量化区间码长loss。训练四轮共耗时`57.545781 s`。候选矩阵保存在`Katrina_attr0_candidate.txt`，完整训练状态保存在`Katrina_attr0_training.npz`。

验证固定使用Katrina的标签零阶外插、数值零阶外插＋空间修正，以及与Tsunami一致的global、MSD、16个排序候选和平滑EB参数。在全部162步的REL `1e-2`和`1e-3`结果之间，按UMC REL `1e-3`对应的`78.724324 dB`线性插值：

| 坐标 | 同PSNR BR | CR/UMC | 相对原始坐标BR | REL 1e-3压缩＋解压时间 |
|---|---:|---:|---:|---:|
| 原始坐标 | `0.625827` | `1.164×` | `0%` | `3.698376 s` |
| 当时的正式矩阵（现为旧矩阵） | `0.343421` | `2.121×` | `-45.125%` | `3.527488 s` |
| 新训练候选矩阵 | `0.448490` | `1.624×` | `-28.336%` | `3.801513 s` |

该次10000样本、第4轮矩阵虽然优于原始坐标，但同PSNR BR比当时的正式矩阵高约`30.594%`，因此当时没有替换。后续逐轮、扩样和训练EB调优发现100000样本、训练REL EB `1e-3`、第2轮和吸收率`0.75`更好，正式矩阵已经更新；新结果见`results/katrina_adjust_coord_ggd_tuning/`。速度来自不同的顺序运行，只用于排查明显退化，不作为矩阵选择依据。
