# Katrina旧坐标变换矩阵复现

本实验确认替换前的Katrina旧正式矩阵能否由旧训练方法复现。训练固定使用二次方距离loss、5个训练近邻、3个等间距训练文件、25%第一次采样、10%第二次采样、4轮`least_squares`、矩阵吸收率0.5、最多100次内层评估和随机种子0；整体矩阵倍率按旧实现每轮归一化后丢弃。三个训练文件为time step 27、80和134，每轮使用31324个目标及156620个点对。

重训矩阵保存在`Katrina_attr0_reproduced.txt`，完整训练状态保存在`Katrina_attr0_reproduced.npz`。重训结果与旧记录的迭代编号、每轮点对数、`nfev`和`njev`完全一致；矩阵六个系数的最大绝对差为`2.435274204515281e-13`，训练loss的最大绝对差为`5.206390873979672e-13`。因此旧矩阵能够由旧方法在当前代码中复现，剩余差异属于数值库和浮点运算末位差异，不是训练流程差异。活动矩阵后来已由更好的码长loss调优结果替换，见`results/katrina_adjust_coord_ggd_tuning/`。
