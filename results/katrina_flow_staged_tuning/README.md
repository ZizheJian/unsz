# Katrina时间流程staged筛选

使用当前冻结的RBF与DAG参数，在全部162个time step和完整五点RD曲线上比较三种标签＋数值流程：

- 标签零阶外插＋数值零阶外插/空间残差；
- 标签一阶内插/空间补充＋数值一阶内插/空间残差；
- 标签anchor8＋数值anchor8内插/空间残差。

三组统一使用Exponential、shape `0.01`、nugget `1e-6`、RBF10、global、16个排序候选、MSD1和`inverse_rank_log2(base=0.8,shift=0.5,max_exponent=7)`。坐标变换使用当前C++ `auto`模式，三组共享同一DAG缓存。

本轮`staged`依次生成标签和值payload并在内存中组合大小，只用于比较BR和PSNR，不生成正式码流、不执行解压，也不使用其时间选择方案。胜出流程需要随后以`fused`模式独立解压并进行正式速度测试。

## 结果

完整162个time step、五点RD曲线的结果如下：

| 流程 | BD-rate vs. 零阶 | PSNR约82 dB时的BR | 对应CR |
|---|---:|---:|---:|
| 零阶 | 0.00% | 0.368985 | 86.724 |
| 一阶内插 | -10.37% | 0.354115 | 90.366 |
| anchor8 | +11.31% | 0.455438 | 70.262 |

一阶内插相对anchor8的BD-rate为`-19.70%`。因此当前参数下，一阶内插在完整共同PSNR区间内压缩效果最好，零阶次之，anchor8最差。旧anchor8结果只覆盖旧代码和参数下的两个相邻误差点，不能用于当前正式流程选择。

## Fused复测

随后使用相同参数对零阶和一阶各运行完整五点`fused`压缩与解压。`fused`结果复现了staged结果：一阶相对零阶的BD-rate为`-10.35%`。

在共同PSNR区间对时间倍率的对数进行积分后，一阶相对零阶为：

| 指标 | 一阶/零阶 |
|---|---:|
| 核心压缩时间 | 1.110× |
| 核心解压时间 | 1.495× |
| 核心压缩＋解压时间 | 1.265× |

因此零阶和一阶均为Pareto候选：一阶以约26.5%的总时间代价换取约10.35%的BD-rate下降，零阶明显更快。anchor8同时劣于一阶的压缩效果，且不再进入正式候选。若正式实验优先平衡速度与压缩效果，保留零阶配置；若优先压缩效果，则选择一阶。
