# Katrina使用Tsunami空间参数

固定Katrina的标签零阶外插与数值零阶外插＋空间修正流程，只把空间参数统一为Tsunami配置：global排序、MSD、RBF10、Matérn-3/2、shape `0.03`、nugget `1e-6`、16个排序候选，以及底数`0.85`、shift `0.5`的连续EB曲线。Katrina继续使用已有坐标变换和两点集最近有效点回退。

全部162步在REL `1e-2`和`1e-3`处分别得到`62.713275 dB / BR 0.162397`和`81.556477 dB / BR 0.375442`，均通过独立解压验证。在UMC REL `1e-3`对应的`78.724324 dB`处对UNSZ的BR作线性插值，得到BR `0.343421`，同PSNR下CR约为UMC的`2.121倍`。REL `1e-3`处UNSZ压缩和解压分别耗时`1.983338 s / 1.544150 s`，总时间为UMC现有结果的`1.080倍`。该时间用于定向核验，不是五个REL EB的几何平均。
