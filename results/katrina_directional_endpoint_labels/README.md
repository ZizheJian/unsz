# Katrina单向零阶内插标签预测

为了让标签和数值共同按照时间一阶内插的递归二分顺序处理，首尾两个time step使用空间标签预测；其余每个time step采用单向零阶内插，只复制已经恢复的左端点或右端点标签。压缩端分别生成两个方向的标签修正流，选择Zstd字节数较小的一侧，并为每个文件记录一个方向bit。解压端读取方向bit后使用同一端点恢复标签。

本实验直接读取全部162步真实标签，使用与当前实现相同的错误位置差分编码和Zstd level 3。160个中间time step中，115个选择左端点，45个选择右端点。

| 标签流程 | 标签码流 |
|---|---:|
| 按时间顺序使用上一time step | `157,615 B` |
| 一阶内插＋空间补充 | `208,177 B` |
| 单向零阶内插，不计方向bit | `231,420 B` |
| 单向零阶内插，包含162个打包方向bit | `231,441 B` |

单向零阶内插比顺序零阶外插多`73,826 B`，即标签码流增大约`46.84%`；比一阶内插＋空间补充多`23,264 B`，增大约`11.18%`。如果每个独立文件暂时用一个完整byte保存方向，总量为`231,582 B`，差异可以忽略。

把该标签码流与数值“一阶内插＋空间补偿”组合，并在`82.694494 dB`处沿BR–PSNR线性插值，预计总BR为`0.290545`、CR为`110.138倍`。它仍比纯空间的BR低约`26.94%`，CR约为纯空间的`1.369倍`；相比分别安排标签和数值顺序的理想两阶段方案，CR只低约`3.00%`。因此它不是最小标签码流，但可以用很小的总体代价换取单一递归time step遍历。
