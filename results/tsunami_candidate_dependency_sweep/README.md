# Tsunami排序候选数与串行依赖扫描

固定六个field共同使用原始坐标、纯空间预测、RBF10、Matérn-3/2核、shape `0.03`、nugget `1e-6`、无趋势项、global排序、MSD评分、排序评分最多使用10个参考点且少于10点时重新查询、连续EB底数`0.85`和shift `0.5`。只改变排序时每次比较的局部候选数，扫描`4,8,12,16,20,24,28,32`。

BR列以候选16为基准，在两条BR–PSNR曲线的共同PSNR范围内直接线性插值BR并比较积分，不使用log BR；负数表示BR更低。耗时为程序内部记录的压缩与解压时间之和，不包含DAG生成、DAG加载和RBF权重预计算。先分别计算每个field的五点几何平均耗时及其相对候选16的倍率，再对六个field等权取几何平均。

“引用上一目标”表示当前目标的10个参考点中包含预测顺序里紧邻的上一个目标。“关键路径”是从DAG依赖关系计算出的最长依赖链；占比为链上点数除以总点数`113885`。

总时间倍率与“引用上一目标”比例的Pearson相关系数为`0.968`。候选4和8会形成覆盖全部点的依赖链；候选12开始打断长链，耗时同步显著下降。候选16位于效果与速度的拐点：候选8的平均BR仅低`0.071%`，但总时间增加`20.8%`；继续从16增加到32只能再缩短约`5.0%`总时间，却使平均BR增加`0.647%`。因此Tsunami六个field的冻结配置统一采用16候选。
