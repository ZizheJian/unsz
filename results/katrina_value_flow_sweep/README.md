# Katrina数值流程初筛

固定标签流程为时间零阶外插，数值使用当前Katrina空间RBF配置，在全部162个time step上比较五种非联合流程。代表点取纯空间在REL `1e-3`处的`82.694494 dB`，其他流程在实测BR–PSNR点之间直接线性插值，不使用log BR。

当前只保留两个候选组合。在`82.694494 dB`下，“标签一阶内插＋空间补充、数值一阶内插＋空间修正”的BR为`0.287794`、CR为`111.191倍`；“标签零阶外插、数值零阶外插＋空间修正”的BR为`0.316656`、CR为`101.056倍`。前一种的BR低约`9.11%`，CR高约`10.03%`。现有实验没有可用于正式比较两者的规范速度数据，因此这里只比较压缩效果。

| 数值流程 | 同PSNR下BR | 同PSNR下CR | CR/纯空间 |
|---|---:|---:|---:|
| 纯空间 | `0.397677` | `80.467×` | `1.000×` |
| 时间零阶外插 | `1.547519` | `20.678×` | `0.257×` |
| 时间一阶内插 | `1.268143` | `25.234×` | `0.314×` |
| 零阶外插＋空间补偿 | `0.316656` | `101.056×` | `1.256×` |
| 一阶内插＋空间补偿 | `0.281816` | `113.549×` | `1.411×` |

一阶内插＋空间补偿最好：同PSNR下BR比纯空间低约`29.13%`，CR约为纯空间的`1.411倍`。纯时间预测本身明显不适合该field，空间补偿是收益来源。

当前`staged`实现仍在每个文件内依次处理标签和值，无法让零阶外插标签使用顺序time step遍历、同时让一阶内插数值使用递归二分遍历。因此，一阶内插相关行先实测空间标签下的数值码流，再替换为上一轮完整实测的零阶外插标签码流；标签与数值码流相互独立，所以各实测点的组合字节数准确，但当前程序尚不能直接生成这种组合容器，耗时也不作为正式结果。所有用于组合的数值码流均通过独立解压验证。

## 标签一阶内插＋空间补充

标签“一阶内插＋空间补充”和数值“时间一阶内插＋空间补偿”采用相同的递归二分time step顺序，因此当前程序可以直接生成组合码流。确切组合在REL `1e-3`和`1.1e-3`处分别得到`82.731872 dB / BR 0.288444`和`82.014969 dB / BR 0.275972`，均通过独立解压验证。在`82.694494 dB`处沿BR–PSNR直线插值得到UNSZ BR `0.287794`、CR `111.191倍`；同一PSNR下UMC插值得到BR `0.908211`、CR `35.234倍`。因此UNSZ的BR低约`68.31%`，CR约为UMC的`3.156倍`。
