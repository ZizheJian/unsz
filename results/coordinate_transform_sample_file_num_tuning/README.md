# Katrina坐标变换训练文件数调优

固定当前正式Katrina零阶外插、RBF10、Exponential、shape `0.01`、nugget `1e-6`、global、16个排序候选、MSD1、当前EB schedule以及第一轮采样率`0.30`，比较训练文件数`2/3/4/5`。

主实验将第二轮总目标数固定为3000，仅改变目标在时间轴上的分布。另补充`4文件×每文件约1000目标`和`5文件×每文件约1000目标`，即第二轮总目标数分别为4000和5000。调优时强制启用坐标变换，每组使用独立DAG并运行完整五点fused压缩与解压。

162个time step下，2/3/4/5个训练文件分别约位于`[40,121]`、`[27,81,134]`、`[20,60,101,141]`和`[16,48,81,113,145]`。因为训练文件的位置会随数量变化，而且3000个第二轮目标会重新分摊，所以更多文件的训练集并不是3文件训练集的超集，结果不要求随文件数单调改善。

## 同PSNR结果

以3个训练文件为基准，在五个正式误差点的共同PSNR区间积分：

| 训练文件数 | BD-rate相对3文件 | 压缩时间比 | 解压时间比 | 压缩+解压时间比 |
| ---: | ---: | ---: | ---: | ---: |
| 2 | +54.039% | 1.0025 | 1.0170 | 1.0084 |
| 3 | 0 | 1 | 1 | 1 |
| 4 | +25.374% | 1.0071 | 1.0258 | 1.0147 |
| 4，第二轮4000目标 | +25.794% | 0.9961 | 1.0055 | 0.9999 |
| 5 | +42.230% | 0.9901 | 1.0030 | 0.9953 |
| 5，第二轮5000目标 | +42.008% | 0.9883 | 1.0118 | 0.9977 |

3个训练文件明显优于2、4和5。将4/5文件的第二轮目标增加到每文件约1000个均没有改善压缩效果，说明更多文件较差并不是因为单文件目标数减少。继续保留默认值`3`和第二轮目标数`3000`。
